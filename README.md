## 三处根改

**1. 渲染底座：Canvas 逐帧手算坐标 → HTML/CSS 卡片自动布局**

固定逻辑尺寸 1080×1920 / 1920×1080，预览只做 CSS `transform: scale()`；导出把**同一份 DOM + 同一份 CSS** 序列化成 SVG `foreignObject` 再光栅化。

由此消失的旧问题：字号时大时小（**主标题统一 `--fs-title`，自适应只防溢出不放大**，详见《字号诊断报告.md》）、中文拆词（`Intl.Segmenter` + 词组 nowrap + 后缀/介词粘连）、重叠越界（交给 flex）、预览与导出两套排版（单一真相源 `FRAME_CSS`）。

**2. 产品形态：8 标签参数台 → 三步**

`填内容 → 选风格 → 出片`。48 套模板、几十项微调、五路混音、逐段音效全部收掉。首次打开就能走完一支片。

**3. 内容结构：课件五阶段 → 平台四拍 + 独立封面**

`封面(00) → 钩子(01) → 反直觉(02) → 拆解(03×N) → 结论(04)`。不再有「念题 / 想一想 / 3·2·1 / 揭晓」。答案只在最后一拍；封面是发布时单独上传的静态图。

## 如实边界

1. **在线人声未在本次验证环境实测**：接口需联网，验证只覆盖 URL 构造、音色列表、并发（用本地 WAV 拦截）、失败提示路径。点「试听一句」自行确认。
2. **WebM 录制测的是 2 秒短片**；完整片长链路相同但未跑满。
3. **MP4 不直出**：浏览器编码器限制，输出 WebM + ffmpeg 命令转码。
4. **字幕是补充短句，不是朗读全文**；悬念句 / CTA 默认来自通用短句池，按题干 hash 稳定取，不是语义生成。
5. **中文断行优先「词组完整 + 填满宽度」**，标点后不强制换行；个别句子可能断在副词前，读得通但不是最优语义断点。
6. **窄屏**（390×844）画布约 300px 高，面板占 38vh，时间轴文字会省略。
7. `foreignObject` 光栅化必须用 `data:` URL —— Chrome 对 `blob:` URL 的 SVG 会污染 canvas，导致 `toBlob` / `captureStream` 失败。
8. 断言约束「不出现已知坏味道」，**替代不了审美判断**；36 张成品图已逐张打开确认，观感仍需你过目。


## v3 本轮：内容编排重做（不是再调字号）

三点投诉逐条落地：

1. **话术按题型分派** —— 科普 / 解说是问答题，不再出现「答案可能和你想的相反」「你选对了吗」。`SCRIPT` 四套独立话术 + `QUIZ_WORDS` 护栏 + `fitHook/fitCta`。
2. **数字与单位整体不可断** —— `1000 米`、`10%`、`20-20-20`、`UV` 各为单一不可断词；拆解帧改「主句 + 数据卡 + 分段进度 + 下条预告」，不再一屏一句话加 40% 留白。
3. **断言驱动四拍** —— 断言（题干 + 钩子 + 看点标签 + 承诺）→ 看点（三层递进）→ 拆解（逐层加码，最反直觉的数据放最后）→ 结论（答案 + **一句话带走** + 来源 + CTA + 免责）。完整策略见《平台发布设计.md》。
